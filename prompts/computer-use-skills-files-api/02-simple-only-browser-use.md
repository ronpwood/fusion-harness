Computer use lets an agent operate software from a screenshot: it clicks, types, and scrolls the way someone at a keyboard would. The new browser use tool extends this to web applications, but it targets elements differently — alongside the screenshot it reads the structure of the page and acts on a specific field or button rather than a screen position. Both tools now support multi-action turns, so Claude can take several actions per model call instead of one.
